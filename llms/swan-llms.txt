# Swan

> Swan is a European banking-as-a-service (BaaS) and embedded-finance platform that lets software companies embed banking -- business accounts with native IBANs, physical and virtual cards, SEPA payments and direct debits, and white-label onboarding -- through a single OAuth 2.0 protected GraphQL Partner API. Swan is a licensed electronic money institution (France ACPR 86245); deposits are safeguarded at BNP Paribas and covered by the French FGDR.

## API

- [Partner API (GraphQL, live)](https://api.swan.io/live-partner/graphql): Production GraphQL endpoint for accounts, cards, payments, onboarding and consent.
- [Partner API (GraphQL, sandbox)](https://api.swan.io/sandbox-partner/graphql): Sandbox GraphQL endpoint mirroring live.
- [API Explorer](https://explorer.swan.io/): Interactive GraphQL explorer, including the Testing API tab.

## Auth

- OAuth 2.0 authorization server: https://oauth.swan.io/
- OpenID Connect discovery: https://oauth.swan.io/.well-known/openid-configuration
- Token endpoint: https://oauth.swan.io/oauth2/token (client_credentials for project tokens, authorization_code for user tokens)
